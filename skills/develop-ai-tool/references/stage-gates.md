# S0-S11 阶段闸门

| 阶段 | 必要产物 | 通过条件 |
|---|---|---|
| S0 治理 | 数据、权限、用户、负责人 | 外部动作和敏感信息边界明确 |
| S1 问题 | 用户任务、现状、失败成本 | 问题可验证，不以工具为问题定义 |
| S2 方法 | 理论与方法证据卡 | 来源、适用条件、内部假设分开 |
| S3 同类 | 自研、官方、开源矩阵 | 不只看功能清单，包含测试与边界 |
| S4 指标 | Excel 指标字典 | 定义、算法、阈值、证据、责任人齐全 |
| S5 基线 | 无工具基线、评测集 | 有正向、负向、边界和机器断言 |
| S6 架构 | 形态决策、资源设计 | 采用最小充分形态 |
| S7 MVP | 源码、脚本、模板 | 官方脚手架；新增脚本已运行 |
| S8 静态 | 校验与功能报告 | 元数据、链接、脚本、安全扫描通过 |
| S9 行为 | A/B、重复试验、Judge | 指标达阈值；安全红线零失败 |
| S10 发布 | 版本、包、哈希、回滚 | 发布范围经授权，限制已声明 |
| S11 监测 | 失败分类、回归集 | 变更可追溯，旧用例持续通过 |

阶段允许回退。S9 发现问题时回到 S5-S7，不用修改评分掩盖失败。
