# 工具形态决策

## 决策顺序

1. 单次任务能用普通 Prompt 完成吗？
2. 是否只是一个项目长期生效的规则？
3. 是否需要跨任务复用的知识、流程、脚本或模板？
4. 是否有多个相关能力，需要统一安装、版本和发布？
5. 是否必须访问外部系统、实时数据或执行远程动作？

| 形态 | 适用条件 | 不适合 |
|---|---|---|
| Prompt | 单次、低风险、上下文短 | 反复复用、需测试发布 |
| Project Instructions/AGENTS.md | 项目内长期规则 | 跨项目安装和独立版本 |
| Skill | 一个可发现的任务能力 | 多能力统一安装、外部连接 |
| Plugin | 多个相关 Skill、脚本、模板或连接器 | 只有一段简单指令 |
| MCP | 外部系统、实时数据、远程动作 | 纯本地知识和流程 |

优先选择最小充分形态。每增加一层，都要增加权限、测试、版本和故障面管理。
