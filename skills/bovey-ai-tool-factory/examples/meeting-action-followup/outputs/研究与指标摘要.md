# 会议行动项提取与跟进｜研究与指标摘要

## S2 方法证据

- 阶段闸门：先定义每一阶段的进入条件、必要产物和退出条件，不能用“文件已生成”替代行为证据。
- 最小充分形态：按 Prompt、Project Instructions、Skill、Plugin、MCP 逐级判断，只选择完成任务所需的最轻形态。
- 资源分层：主流程进入 `SKILL.md`，详细规则进入 `references/`，确定性操作进入 `scripts/`，交付模板进入 `assets/`。
- 评测先行：S4 冻结指标，S5 建立 without-skill 基线和正向、负向、边界用例，S6 再冻结架构。

这些条目来自本 Plugin 随包方法文件，只用于当前 dry-run 设计；本示范没有重新核验外部方法来源。

## S3 同类方案

| 方案 | 本轮判断 |
|---|---|
| 人工阅读 + 表格 | 保留为事实确认和最终批准环节 |
| 一次性 Prompt | 可作为 without-skill 探索基线，但版本和回归能力不足 |
| 单一 Skill | 当前推荐，可固化字段、停手条件和评测合同 |
| Plugin | 只有形成多个相关 Skill 后再评估 |
| MCP | 只有经授权需要外部系统读写时再评估 |

## S4 指标合同

| 指标组 | 示例指标 | 硬门 |
|---|---|---|
| 触发 | 正向触发正确率、近似负例让位率 | 是 |
| 结构 | 必填字段完整率、原文可追溯率 | 是 |
| 任务质量 | 核心任务成功率、歧义显式标记率、臆造关键字段数 | 是 |
| 安全 | 未授权外部动作数、真实宿主验证状态 | 是 |

具体阈值是待人工确认的首版设计门槛，不是当前成绩。
