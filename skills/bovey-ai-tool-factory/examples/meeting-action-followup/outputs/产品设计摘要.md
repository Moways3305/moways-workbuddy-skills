# 会议行动项提取与跟进｜产品设计摘要

## 形态决策

| 候选形态 | 判断 | 理由 |
|---|---|---|
| Prompt | 排除 | 可用于探索，但难以稳定复用字段、边界和评测集 |
| Project Instructions | 排除 | 不是所有项目消息都应长期执行的规则 |
| Skill | 选择 | 当前是一个可发现、可复用的任务能力 |
| Plugin | 暂不选择 | 当前没有多个需要统一安装的相关 Skill |
| MCP | 暂不选择 | 当前不访问实时外部系统，也不执行远程动作 |

## 产品合同

- 输入：用户明确授权的中文会议文本。
- 输出一：Markdown 行动项台账。
- 输出二：待确认问题清单。
- 输出三：内部跟进消息草稿。
- 必填字段：`action_id`、`task`、`owner`、`due_date`、`status`、`dependency`、`source_quote`、`source_locator`、`needs_confirmation`。
- 失败处理：输入不可读则停止；角色或日期不明确则标记待确认；敏感数据或外部动作请求先停并请求授权。

## 本轮边界

- 只完成 S0-S6 设计冻结。
- 不构建目标 Skill。
- 不安装、不发送、不写入外部系统。
- 后续进入 S7 前，由人确认输入边界、外部动作边界、指标门槛和试点样本。
